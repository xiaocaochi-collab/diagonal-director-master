# 场景图原生视觉分析规范

用户提供场景照片、三维场景图、建筑平面图、走位图、机位图、灯光布局图或氛围参考图时，使用当前宿主模型的原生视觉能力。不得调用外部视觉 API，不依赖指定模型、密钥或脚本。

## 1. 总原则

- 先识别图片类型，再决定允许提取的信息。
- 只记录图片直接可见、图中明确标注或可由可靠参照有限推断的内容。
- 单张透视图未展示的区域必须写「未知」或「图片未覆盖」。
- 不为填满表格编造四面墙、房间尺寸、真实方位、画外光源或隐藏结构。
- 所有结果标记为：已确认 / 合理推断 / 未知。
- 用户确认和修正的内容标记为「用户确认·已锁定」，后续分析不得覆盖。

## 2. 图片类型与提取边界

| 图片类型 | 可以提取 | 不得作为事实 |
|----------|----------|--------------|
| 实景照片 / 三维场景截图 | 可见空间、结构、家具、材质、光源、受光、遮挡 | 未展示墙面、真实方位、精确尺寸、画外空间 |
| 建筑平面图 | 明确绘制或标注的结构、尺寸、门窗、通道 | 未标注的灯光、颜色含义、人物和机位 |
| 走位图 | 明确标注的人物位置、朝向、移动路线 | 未标注机位、光源或时间关系 |
| 机位图 | 明确标注的摄影机位置、方向、镜号、轨迹 | 未标注人物、光源或剪辑时间关系 |
| 灯光布局图 | 明确标注的灯位、方向、照射区和开关状态 | 普通颜色、阴影或箭头的自创含义 |
| 氛围参考图 | 影调、冷暖、对比、质感和情绪倾向 | 空间结构、灯位、人物站位和道具事实 |

同一图片兼具多种类型时，可以分别提取，但必须注明每条结论的图中依据。

```markdown

```

### 尺度规则

- 图中有明确尺寸标注时可以直接记录。
- 有可信参照物且透视关系足够清楚时，只给大致范围并写明依据。
- 没有可信参照时使用“大致较窄/较宽、仅容单人通过”等关系性描述。
- 不要求每个距离都有数字，不输出伪精确小数。

### 方位规则

- 图中明确标有东南西北时使用真实方位。
- 没有真实方位依据时，只使用“当前图片左/右、前景/中景/后景”，并注明该关系仅对当前视角成立。
- 不得把图片左侧永久写成房间西侧。

## 4. 光影证据报告

完整加载 `lighting-system.md`，输出：

```markdown
## 光影证据报告

| 项目 | 观察或推断结果 | 图中依据 | 可靠程度 | 锁定状态 |
|------|----------------|----------|----------|----------|
| 可见光源 |  |  |  |  |
| 自然光入口 |  |  |  |  |
| 当前受光区域 |  |  |  |  |
| 阴影方向与边缘 |  |  |  |  |
| 冷暖倾向 |  |  |  |  |
| 高光与反射 |  |  |  |  |
| 画外光源 | 未知，除非有明确标注 |  |  |  |
```

- 图片只能证明拍摄时呈现的光影，不能直接决定正式分镜灯光。
- 固定灯具存在不等于本场开启。
- 不从普通照片编造灯具功率、精确色温、照度、光比、入射角或摄影机曝光参数。

## 5. 人物与机位参考报告

仅在图片确实包含人物、站位或机位信息时输出：

```markdown
## 人物与机位参考报告

### 人物
| 人物或标记 | 位置 | 朝向/视线 | 移动路线 | 可靠程度 |
|------------|------|-----------|----------|----------|

### 摄影机
| 机位或标记 | 位置 | 高度 | 观察方向 | 运镜轨迹 | 可靠程度 |
|------------|------|------|----------|----------|----------|

### 无法确认
- 
```

- 没有人物标记时，不推断具体人物站位。
- 没有机位标记时，可以说明照片的观察方向，但不得把拍摄照片的位置锁定为正式机位。
- 机位图没有明确景别时，不依据箭头长度猜测景别。

## 6. 输出后的质量检查

- 是否把未展示区域误写成完整空间？
- 是否生成了无依据的真实方位或精确尺寸？
- 是否区分已确认、合理推断和未知？
- 是否把氛围图误作空间事实？
- 是否把固定灯具的存在误作开启状态？
- 是否把画面左右误作永久空间方位？
- 是否把照片拍摄位置误作正式机位？
- 是否覆盖了用户已经锁定的事实？

发现问题时先修正报告；无法可靠修正时集中向用户确认。
