# DIAGONAL 品牌与成果署名

本模块只管理工具品牌的可见呈现，不增加导演决策步骤、确认节点或项目事实源。

## 名称与现有标识

- 正式名称：`DIAGONAL导演大师`；技能标识：`diagonal-director-master`。
- 浅色背景使用 [黑色标识](../assets/logo-black.png)，深色背景使用 [白色标识](../assets/logo-white.png)。保持原始比例，不重绘、不拉伸。
- 品牌与项目名称分开呈现；保留用户原有作者、编剧、导演及制作单位信息。
- 所有入口统一使用正式名称。普通聊天答复、自检报告与待确认问题无需重复品牌口号。

## 正式文字成果

新建或按用户要求修订的正式分镜、全片分析及其他独立交付文档，默认在全文末尾加一次工具落款：

```markdown
---
*制作工具：DIAGONAL导演大师*
```

全片合并时移除各场重复的工具落款，只在合并文档末尾保留一次。署名不进入镜号、正文对白、连续性表、灯光卡或机器状态文件；不自动批量改写历史成果。

提示词交付文档可以在末尾使用相同落款，但所有可复制的 MJ、Seedance 或其他生成提示词须置于单独代码块中，落款置于代码块外。用户要求纯提示词、纯文本或机器可读数据时，正文不加署名；原有输出结构和工具解析要求优先。

在正式提交前处理落款，再通过原有文件事务归档；不为补署名绕过确认或直接覆盖正式文件。

## 图表与资产库

- 情绪曲线 PNG 默认在底部留白右侧绘制 `DIAGONAL / DIRECTOR MASTER`，使用低对比文字，与左侧数据源说明分行放置，不遮挡曲线、坐标、场次或情绪标签。
- 使用 [情绪曲线绘图脚本](../scripts/render_emotion_curve.py) 自动绘制；用户要求无署名图时加 `--no-branding`。
- 资产库保留现有黑白标识和页脚品牌，预览窗口显示工具名称；上传素材、预览原图、原视频和下载原文件不叠加水印。
- 需要给用户图片或视频本体加水印时，先依据用户的明确要求另行处理。本模块不会把品牌文字写进生成画面的提示词以模拟水印。

## 用户控制与署名范围

用户明确要求改变位置、文案或移除成果署名时遵从，不反复询问。工具署名仅说明制作流程使用了本工具，不宣称 DIAGONAL 是用户剧本、素材或成片的作者，也不代替软件使用许可。
