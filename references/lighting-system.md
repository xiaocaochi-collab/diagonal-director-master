# Lighting System Reference（光影系统参考）

本文件定义 Storyboard skill 的全片光影圣经、场景图光影证据、场景灯光卡、逐镜光影写法和连续性检查。生成或修订光影内容前必须加载本文件。

---

## 1. 系统职责

光影系统采用四层结构：

```text
全片光影圣经
    ↓
场景图光影证据 + 剧本事实 + 空间参照表
    ↓
每场独立场景灯光卡
    ↓
逐镜光影状态与连续性检查
```

- **全片光影圣经**：定义整部影片的共同视觉原则。
- **场景图光影证据**：记录图片能证明或合理推断的内容，不做最终导演决定。
- **场景灯光卡**：本场最终灯光设计，是逐镜光影唯一事实源。
- **逐镜光影状态**：记录本镜实际呈现和从上一镜继承或发生的变化。

---

## 2. 光影决策优先级

本模块直接服从主入口的统一规则优先级，不反向加载主入口，也不把旧的灯光锁定放在新版剧本明确事实之前。在同一权威等级内部，光影证据按“场景图已确认事实 → 全片光影圣经 → 场景图合理推断 → 模型纯文本推断”使用；较低层只能补充未知项，不能覆盖较高层。

- 高层级与低层级冲突时使用高层级。
- 不得把互相冲突的光源强行合并。
- 用户修正内容标记为「已锁定」，后续分析不得覆盖。
- 仍无法裁决时向用户说明并等待确认。

## 3. 定性描述边界

默认使用定性电影语言：

- 光质：硬、偏硬、柔、偏柔、漫射。
- 冷暖：冷、偏冷、中性、偏暖、暖、冷暖混合。
- 明暗：高调、中间调、低调；低、中、高对比。
- 阴影：浅、密、柔边、硬边、局部覆盖、大面积覆盖。
- 曝光：优先保证面部、关键道具、环境层次或剪影。

除非用户或资料明确提供，不得自行编造：

- 照度与勒克斯数值；
- 灯具功率；
- 精确开尔文色温；
- 精确光比；
- 精确入射角；
- 光圈、ISO、快门等曝光参数。

## 4. 全片光影圣经模板

```markdown
## 全片光影圣经

- 总体影调：
- 基础冷暖关系：
- 人物面部受光原则：
- 阴影原则：
- 曝光优先级：
- 全片光影变化曲线：
- 禁用方式：
```

### 编写原则

1. 每条必须服务剧本类型和整体基调。
2. 只定义共同原则，不逐场规定具体灯位。
3. 全片变化曲线描述总体趋势，不允许正式分镜出现跨场比较句。

## 5. 图片类型与光影提取权限

| 图片类型 | 可以提取 | 禁止推断 |
|----------|----------|----------|
| 实景照片 / 三维场景截图 | 可见光源、自然光入口、受光区域、阴影、冷暖倾向 | 精确灯位、功率、画外光源事实 |
| 灯光布局图 | 明确标注的灯位、方向、照射区域 | 未标注颜色或箭头的含义 |
| 建筑平面图 | 门窗、空间结构、明确标注灯具 | 将普通颜色、阴影当成灯光 |
| 走位图 | 人物站位和移动路线 | 将走位箭头当作光向 |
| 机位图 | 摄影机位置、镜头方向 | 将机位箭头当作光向 |
| 氛围参考图 | 影调、冷暖、对比和情绪倾向 | 空间结构、真实灯位和光源状态 |

图片方向必须转换为空间坐标。优先写"北墙窗户""沙发右侧台灯"，避免只写"画面左侧光"。

```markdown
### 第X场 场景图光影证据

|------|----------------|----------|----------|----------|
| 可见光源 |  |  | 已确认/合理推断/未知 |  |

| 阴影方向 |  |  |  |  |
| 冷暖关系 |  |  |  |  |
| 画外光源 |  |  |  |  |
```

### 可靠程度

- **已确认**：图片直接可见、图中明确标注、剧本明确写出或用户确认。
- **合理推断**：根据阴影、亮区或空间关系推断。
- **未知**：信息不足。

证据表不得直接复制到正式分镜。必须先由场景灯光卡裁决。

## 7. 场景灯光卡模板

```markdown
### 第X场 场景灯光卡

- 场景 / 时间：
- 本场情绪目标：
- 基础影调：
- 动机光源：
- 主光：来源、空间位置、方向、光质、冷暖倾向、主要作用对象
- 辅助光 / 背景光：
- 曝光重点：
- 基础阴影区域：
- 人物可活动明区：
- 人物可活动暗区：
- 剧情开始时光源状态：
- 光影变化节点：变化事件、变化后状态、触发原因
- 与前后连续场次的关系：
- 信息来源：
- 可靠程度：
```

### 场景灯光卡规则

1. 每个场次独立建立，即使地点相同也不能自动复用灯光状态。
2. 固定灯具"存在"不等于本场"开启"。
3. 图片中的勘景光、默认顶灯或临时工作灯不自动成为最终设计。
4. 光影变化必须有触发：人物移动、遮挡、开关灯、门窗变化、时间变化、闪烁或明确导演设计。
5. 无场景图时可以推断，但需标明来源和可靠程度。
6. 场景灯光卡是逐镜光影的唯一事实源。

## 8. 逐镜光影公式

```text
光源来源 → 主体或空间受光 → 明暗、阴影与高光分布 → 本镜变化
```

示例：

```text
光影：右侧台灯形成暖色柔侧光，妻子右侧面部明亮，左侧保留暗部；背景厨房处于冷暗区域。妻子前倾时，眼睛进入台灯高光。
```

无变化时：

```text
光影：沿用本场灯光卡，人物停留在台灯暖色侧光区，背景保持冷暗。
```

## 9. 光影状态追踪表

```markdown
| 镜号 | 光源状态 | 人物所在光区 | 主受光方向 | 阴影/高光状态 | 本镜变化 | 变化原因 |
|------|----------|--------------|------------|---------------|----------|----------|
```

追踪表为内部校验数据，不写入最终分镜文件。发现问题时，正常模式展示相关行并等待用户确认；工业模式按本场授权先内部修正与复检，无法在剧本和已锁定事实范围内解决时才暂停询问。

## 10. 光影自检

### 物理合理性

- 光源是否存在明确来源或导演设计依据？
- 光源固定位置是否与空间参照表一致？
- 正反打后固定光源是否仍处于同一空间位置？
- 人物移动后受光是否合理变化？
- 遮挡是否改变阴影或高光？
- 光源关闭后是否仍残留其高光或阴影？

### 连续性

- 同一时间连续镜头的光源状态是否继承？
- 人物主受光方向是否无理由翻转？
- 冷暖、光质和明暗是否无理由跳变？
- 门窗开启、灯光闪烁和环境变化是否更新状态？
- 同一地点跨场出现时，是否区分了独立时间和灯光状态？

### 叙事一致性

- 光影是否服务本场情绪目标和本镜画面重点？
- 变化是否发生在正确的情绪或剧情节点？
- 是否为了"好看"加入无动机彩光或无来源轮廓光？
- 曝光重点是否错误泄露了应被隐藏的信息？
- 面部微表情是否在当前受光条件下真实可见？

### 证据管理

- 合理推断是否被误标为已确认？
- 用户锁定字段是否被覆盖？
- 氛围图是否被错误当作空间或灯位事实？
- 图片的画面左右是否被错误当作房间固定方向？

---

## 11. 固定确认流程

- 第 0 步展示并确认全片光影圣经。
- 每场第①步展示并确认场景灯光卡和光影叙事曲线。
- 第③步自检报告汇报光影检查结论；正常模式发现问题时展示状态追踪相关行并等待确认，工业模式内部处理后在本场定稿时简述结论。

## 12. 常见错误

### 错误：图片观察结果直接控制正式分镜

```text
图片里顶灯开启，所以本场必须使用顶灯。
```

正确：

```text
图片确认房间中央存在顶灯；场景灯光卡根据剧情决定本场关闭顶灯，仅使用窗光与台灯。
```

### 错误：一张白天场景图跨场复用

```text
同一客厅所有场次均使用白天窗光。
```

正确：

```text
空间结构跨场复用；白天、傍晚、夜晚和停电场次分别建立灯光卡。
```

### 错误：正反打后主光位置翻转

```text
正打光从画面左侧来，反打仍强行写画面左侧来。
```

正确：

```text
固定光源始终来自北墙窗户；根据机位变化，它可出现在画面不同侧，但空间位置不变。
```

### 错误：暗区人物仍完整展示微表情

```text
人物处于剪影中，仍详细描述双眼高光和嘴角细纹。
```

正确：

```text
只描述轮廓、局部眼神或可见面部区域，不新增无来源补光。
```
