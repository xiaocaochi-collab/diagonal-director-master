# Seedance 对角视场角与可见光学结果系统

本系统只在把第⑤步已定稿分镜编译为 Seedance 2.0 提示词时加载。它把传统“焦段标签”改为模型更容易执行的四层控制：

```text
镜头内容类型
→ 对角视场角
→ 摄影机物理距离
→ 可见光学结果
```

它不改变正式镜头、整场一条提示词、中文输出或现有确认流程。

## 1. 核心规则

- 对角视场角和可见结果是主要控制；毫米焦段、镜头品牌、光圈、ISO和摄影机型号不作为主要光学指令。
- 每个正式镜头只选择一种主要光学性格；默认整镜固定对角视场角。只有正式分镜明确要求光学变焦时，才允许在同一镜头记录起始与结束视场角。
- 视场角必须服从景别、空间、主体数量、表演可见性和导演意图，不得为套用模板改变构图。
- 摄影机物理距离必须与场地事实、遮挡、人物比例和机位可达性相容。
- 可见结果必须描述画面实际呈现：透视扩张或压缩、环境可读范围、主体比例、前后景分离、直线是否保持、对焦范围和遮挡。
- 如果正式分镜同时要求互不相容的环境全貌、紧特写和微距细节，报告冲突并返回原流程；不得擅自加切镜。

## 2. 内容类型判断

编译前为每个镜头选择一个主要内容类型：

- **自然观察与常规叙事**：人物和环境关系自然、无明显透视强调；
- **环境动作与空间建立**：空间地理、多人位置、近身动作或环境尺度是重点；
- **人物中近景**：面部稳定、表演可读、背景适度分离；
- **情绪特写**：眼神和细小表演优先，环境信息退后；
- **远距离观察**：窥视、体育转播、野生动物或隔着障碍观察；
- **局部细节**：道具、手部或微小动作是唯一重点。

内容类型由正式分镜决定。一个镜头存在多个内容时，选择承担主要叙事功能的类型，不把所有类型堆进同一个光学块。

## 3. 视场角选择表

距离为编译起点，不是伪精确硬参数；若已确认场地尺度不同，以空间事实和可见结果为准。

| 对角视场角 | 主要用途 | 建议物理距离 | 必须呈现的可见结果 |
|------------|----------|--------------|--------------------|
| `107°` 宽广直线透视 | 大尺度空间、强前景、近身环境动作 | 距前景主体约0.5–0.8米 | 前景明显放大，环境延伸到画面边缘，纵深强，建筑直线保持笔直，无鱼眼弯曲 |
| `84°` 经典广角 | 多人空间关系、沉浸式近距离动作、环境人像 | 距主体约1–1.5米 | 主体有近距离存在感，环境仍完整可读，透视扩张自然，边缘不形成鱼眼 |
| `47°` 标准自然视野 | 常规叙事、纪录式动作、自然人物与环境关系 | 距主体约3–5米 | 人体比例自然，无明显广角拉伸或长焦压缩，背景清楚但不抢主体 |
| `29°` 短长焦人像 | 中近景、稳定面部和适度背景分离 | 距主体约4–6米 | 靠镜头覆盖取得近景而非贴近人物，面部比例稳定，背景轻度压缩并柔化 |
| `18°` 经典长焦 | 紧特写、孤立人物、强背景压缩 | 距主体约6–8米 | 眼睛或关键面部区域清晰，背景明显压缩并化为柔和虚化，观察距离感明确 |
| `8°` 超长焦观察 | 远距离窥视、转播式或障碍后观察 | 距主体约20–25米 | 极强背景压缩，只有主体清晰；前景遮挡形成大块柔焦形状，画面具有远距离观察感 |

不得为了匹配距离数字移动正式人物或改变已确认场地。空间不足时优先保持正式机位、构图和所需可见结果，并在确认卡说明距离受到场地限制。

## 4. 内容与视场角匹配

- 环境、空间、身体靠近摄影机或多人地理关系：优先 `84°` 或 `107°`；没有明显广角意图时使用 `47°`。
- 自然常规叙事：优先 `47°`。
- 人物中近景：优先 `29°`。
- 情绪特写：优先 `18°`；若仍需大量环境信息，不得同时要求极强背景虚化。
- 远距离观察：优先 `8°`，且需要正式构图允许的前景遮挡；没有遮挡依据时不强加。
- 局部细节：优先 `29°` 或 `18°`；不能在同一镜头同时要求宽广环境地理。

视场角不是景别名称。“大全景、近景、特写”仍来自正式分镜；光学系统只解释如何实现该景别及其透视结果。

## 5. 可见结果写法

每镜光学块按以下顺序编译：

```text
[X°对角视场角]；摄影机位于[已确认或可行距离/相对位置]；
[主体比例与透视]；[环境可读范围或背景压缩]；
[前景/背景与对焦结果]；[直线、边缘或遮挡约束]。
```

示例只说明句法，不可照抄到无关镜头：

```text
84°对角视场角，摄影机距人物约1.2米；近距离透视使前景人物具有明确存在感，同时保留门口、长桌和后墙的空间关系；建筑直线保持笔直，画面边缘无鱼眼弯曲。
```

```text
18°对角视场角，摄影机从约7米外取得人物紧特写；面部比例稳定，焦点锁在双眼，背景被明显压缩并柔化为低辨识色块，近景来自镜头覆盖而非摄影机贴近人物。
```

## 6. 推轨、拉轨与光学变焦

先按正式分镜判定摄影机发生的是物理位移还是光学变焦，不得互相替代：

- **推轨/拉轨/靠近/远离**：对角视场角保持固定，摄影机物理距离随运动路径变化；主体比例、透视和前后景视差会随距离改变。确认卡记录固定视场角和起点→终点的物理距离或相对位置。
- **光学变焦/变焦推近/变焦拉远**：摄影机物理位置保持固定，对角视场角按起始→结束变化；主体画面占比改变，但摄影机没有产生推轨式视差。确认卡同时记录起始→结束视场角和固定机位。
- **复合运动**：只有正式分镜明确同时要求摄影机位移与光学变焦时才允许；分别记录两条变化和可见结果，不得凭“推近”“拉远”等含混词自行发明希区柯克变焦。

无法判断“推近/拉远”指物理移动还是光学变焦时，按正式分镜的主运镜和空间结果消歧；仍无法确定则列入现有编译确认卡，不猜测、不新增确认步骤。

## 7. 多镜一致性

- 同一镜头内部不改变视场角，不用平滑变焦代替切镜；正式分镜明确要求变焦时除外。
- 相邻镜头使用相同视场角时，保持同一光学结果，不因景别文字自动漂回中性视野。
- 正式切镜确实改变内容类型时，可以改变视场角；同时保持人物、空间、轴线、视线、光向、服装、伤情、道具和环境状态。
- 不使用大段通用否定词；只有存在高风险时，在对应镜头局部写短锁。

广角局部锁示例：

```text
全镜保持宽广直线透视和深度可读的环境关系，不转成长焦人像效果；建筑边缘保持笔直。
```

长焦局部锁示例：

```text
全镜保持远距离长焦压缩，近景来自镜头覆盖而非摄影机靠近；背景持续柔化，不转成广角环境覆盖。
```

只在过去生成或当前构图确有漂移风险时加入，不机械重复。

## 8. 与灯光、表演和空间的关系

- 光学方案不得改变场景灯光卡；浅景深或背景柔化不能凭空制造面部补光或眼神光。
- 表演细节必须在当前视场角、景别、距离、对焦和受光条件下可见。
- 广角近距离不得无依据扭曲面部；人物特写若必须稳定面部，选择 `29°` 或 `18°`。
- 长焦压缩不得破坏已经确认的人物与地标实际距离；它只改变画面中的视觉压缩结果。
- 地点参考控制空间、材质和地标，不自动控制正式机位和视场角。
- 风格参考不得覆盖主体位置、视场角、可见光学结果、动作或光向。

## 9. 编译确认与自检

在现有 Seedance 编译确认卡的逐镜摄影方案中记录：

- 对角视场角：固定值；仅正式分镜明确光学变焦时写起始→结束；
- 摄影机物理距离或受场地限制的相对位置：固定机位；仅物理位移时写起点→终点；
- 主要可见光学结果；
- 选择依据；
- 必要的局部防漂移锁。

输出前检查：

- 内容类型是否来自正式分镜？
- 视场角是否与景别、主体数量和叙事重点相容？
- 摄影机距离是否符合空间事实和机位可达性？
- 是否描述了可见光学结果，而不只写一个角度数字？
- 是否错误混合广角地理、紧特写和微距内容？
- 同一镜头是否发生无依据的视场角变化？
- 是否把推轨/拉轨错误写成光学变焦，或把光学变焦错误写成摄影机位移？
- 视场角变化与物理距离变化是否分别写清，且都能指向正式分镜依据？
- 光学结果是否与构图、表演可见性、灯光和连续性一致？
- 是否仍以毫米焦段、光圈、品牌或ISO作为主要控制？

发现必须改变正式镜头才能解决的问题时停止编译，返回原分镜流程等待用户裁决。
